三步创建需求 Workspace

领域 Harness 提供背景和约束；PRD 是需求范围和验收依据。创建后，可直接在 Workspace 中使用 Codex、Claude 或任意 IDE 推进交付。

1

绑定领域 Harness

只读挂载产品白皮书、领域记忆、代码入口、领域 skills 与 rules。一份需求只绑定一个领域。

2

输入需求

需求名称用于创建独立 Workspace；项目目录由工作台设置提供，也可在创建时临时调整。

3

导入 PRD

可选。先带入本地需求材料；飞书、内部文档等会作为统一连接器接入。

领域和团队级能力会形成当前需求的“生效能力清单”；不会把公共知识库写回或修改。
