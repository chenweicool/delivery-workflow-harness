# 00 加载上下文

## 目标

加载公共知识快照，汇总本次需求需要用到的背景信息。

## 输出要求

- 输出必须是中文。
- 内容保持简洁，只写和本次需求有关的上下文。
- 没有证据的内容不要扩写；缺失信息只列具体缺口。
- 不要写泛泛兜底、免责声明或与后续阶段无关的建议。

## 允许读取

- `AGENTS.md`
- `CLAUDE.md`
- `context/**`
- `prd/**`
- 交付配置里的本地应用目录，仅用于识别候选应用、代码入口、业务术语和已有接口/模块边界。

## 禁止事项

- 禁止修改代码。
- 禁止生成实施方案。
- 禁止决定最终应用范围。
- 禁止做大范围代码审计；只提取和 PRD 直接相关的上下文线索。

## 输出

写入 `design/context-summary.md`。

## 输出结构

```md
# 上下文摘要

## 1. 需求概览

## 2. 已加载规则与上下文来源

## 3. 业务术语

## 4. 候选系统范围

## 5. 已知风险

## 6. 缺失背景与待补充信息
```
